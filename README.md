# 역량 기반 채용공고 매칭 서비스

JD 본문의 요구 역량과 내 역량을 대조해 채용공고를 매칭하는 서비스입니다.

## 프로젝트 구조

```
project-root/
  backend/               # FastAPI (조회·매칭 API)
  frontend/              # React + TypeScript
  crawler/               # 크롤링 스크립트 (GitHub Actions가 실행)
  .github/workflows/     # cron 스케줄 크롤링
```

## 실행 방법

### Backend

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env   # 환경변수 설정
uvicorn app.main:app --reload --port 8000
```

- API: http://localhost:8000
- Health check: http://localhost:8000/health

### Frontend

```bash
cd frontend
npm install
npm run dev
```

- 앱: http://localhost:5173

## 기술 스택

- Frontend: React (Vite) + TypeScript + Tailwind CSS
- Backend: Python + FastAPI + SQLAlchemy
- Database: Supabase (PostgreSQL)
- AI: OpenAI API (GPT-4o)
- Crawling: Playwright + GitHub Actions cron

### 크롤러 설정

1. Supabase 프로젝트에서 아래 SQL을 실행해 `job_posting` 테이블을 만듭니다.
2. 로컬 `crawler/.env`와 GitHub 저장소 Settings > Secrets and variables > Actions에 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`를 등록합니다. service role key는 프론트엔드에 노출하지 않습니다.
3. 로컬에서는 `crawler/.env`에 두 환경변수를 작성하고, 저장소 루트에서 `pip install -r crawler/requirements.txt` 및 `playwright install chromium`을 실행합니다. 프로젝트 URL은 `https://tiwzyhbuhjsqdlppdjzz.supabase.co` 형식입니다.
4. `python crawler/run.py`로 수동 실행할 수 있습니다. 기본 목록 URL이나 페이지 수는 `LINKAREER_URL`, `CRAWL_MAX_PAGES` 환경변수로 변경합니다.

GitHub Actions의 cron은 UTC 기준이므로 `crawl.yml`은 한국 시간 07:00, 14:00, 19:00에 실행됩니다. 공고 URL을 고유 키로 사용해 이미 저장된 공고는 건너뛰고 새 공고만 추가합니다.

새 공고 스키마와 제출사항·자소서 문항 테이블은 [crawler/schema.sql](crawler/schema.sql)의 SQL 전체를 Supabase Dashboard > SQL Editor에서 한 번 실행해야 합니다. 실행 후 다음 명령으로 수집을 확인합니다.

```powershell
C:/Users/6152/anaconda3/envs/myenv/python.exe crawler/run.py
```

```sql
create table public.job_posting (
  id bigint generated by default as identity primary key,
  source_url text not null unique,
  title text not null,
  company text not null default '',
  description text not null default '',
  deadline text not null default '',
  raw_data jsonb not null default '{}'::jsonb,
  collected_at timestamptz not null default now()
);
```
